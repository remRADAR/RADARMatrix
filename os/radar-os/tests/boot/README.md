# RADAR OS boot evidence

Each architecture result must record:

- image path and SHA-256;
- target architecture and QEMU version;
- machine, CPU, firmware, memory, disk, network, and timeout;
- exact command and environment;
- build, firmware, kernel, userspace, and desktop status separately;
- serial/console log path;
- exit status and fatal-error review;
- operator and date.

Stage 0.1 has no image and no QEMU tools in the environment. The correct current status for both AMD64 and ARM64 is **BLOCKED**, not PASS.
