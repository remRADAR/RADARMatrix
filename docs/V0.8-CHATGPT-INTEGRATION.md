# RADARMatrix v0.8 ChatGPT Integration Guide

## Overview

This document describes the RADARMatrix v0.8 foundation integration with ChatGPT via Model Context Protocol (MCP).

## Integration Architecture

```
ChatGPT / Claude
       ↓
   MCP Client
       ↓
RADARMatrix MCP Endpoint
       ↓
 RADARMatrix Gateway
    (v0.8 Foundation)
       ↓
    Seven MCP Tools
       ↓
Context Retrieval Engine
  (Production: Cloudflare)
```

## MCP Tool Manifest

RADARMatrix exposes seven MCP tools to ChatGPT:

### Read Operations (VIEWER+)

#### 1. `radar.search`
**Purpose**: Full-text and semantic search
**Permission**: VIEWER+
**Input**:
```json
{
  "workspace_id": "w_123",
  "query": "search terms",
  "limit": 10,
  "offset": 0
}
```
**Output**:
```json
{
  "results": [
    {
      "id": "doc_1",
      "title": "Document Title",
      "excerpt": "...",
      "relevance_score": 0.95
    }
  ],
  "total": 42
}
```

#### 2. `radar.recall`
**Purpose**: Retrieve decisions from decision log
**Permission**: VIEWER+
**Input**:
```json
{
  "workspace_id": "w_123",
  "decision_id": "dec_456 (optional)",
  "limit": 20
}
```
**Output**:
```json
{
  "decisions": [
    {
      "decision_id": "dec_456",
      "recorded_by": "user_123",
      "recorded_at": "2026-08-18T10:30:00Z",
      "rationale": "...",
      "status": "active",
      "immutable": true
    }
  ],
  "memories": []
}
```

#### 3. `radar.get_context`
**Purpose**: Load workspace context
**Permission**: VIEWER+
**Input**:
```json
{
  "workspace_id": "w_123"
}
```
**Output**:
```json
{
  "workspace_id": "w_123",
  "name": "Workspace Name",
  "created_at": "2026-01-01T00:00:00Z",
  "config": {
    "default_role": "viewer"
  },
  "entities": []
}
```

#### 4. `radar.get_project`
**Purpose**: Get project metadata
**Permission**: VIEWER+
**Input**:
```json
{
  "workspace_id": "w_123",
  "project_id": "proj_789"
}
```
**Output**:
```json
{
  "project_id": "proj_789",
  "name": "Project Name",
  "description": "...",
  "created_at": "2026-01-01T00:00:00Z",
  "updated_at": "2026-08-18T00:00:00Z",
  "entities": []
}
```

#### 5. `radar.get_entity`
**Purpose**: Get entity details
**Permission**: VIEWER+
**Input**:
```json
{
  "workspace_id": "w_123",
  "entity_id": "ent_321"
}
```
**Output**:
```json
{
  "entity_id": "ent_321",
  "type": "person|document|concept",
  "name": "Entity Name",
  "created_at": "2026-01-01T00:00:00Z",
  "data": { "custom_fields": "..." },
  "relationships": []
}
```

### Write Operations

#### 6. `radar.remember` (CONTRIBUTOR+)
**Purpose**: Record data to workspace memory
**Permission**: CONTRIBUTOR+
**Input**:
```json
{
  "workspace_id": "w_123",
  "content": "Memory content to store",
  "tags": ["tag1", "tag2"],
  "metadata": { "key": "value" }
}
```
**Output**:
```json
{
  "memory_id": "mem_abc123",
  "recorded_by": "user_123",
  "recorded_at": "2026-08-18T10:30:00Z",
  "immutable": true
}
```

#### 7. `radar.record_decision` (EDITOR+)
**Purpose**: Log decision to decision log
**Permission**: EDITOR+
**Input**:
```json
{
  "workspace_id": "w_123",
  "decision": "The decision being made",
  "rationale": "Why this decision was made",
  "context": "Background and context (optional)",
  "affected_entities": ["ent_1", "ent_2"]
}
```
**Output**:
```json
{
  "decision_id": "dec_xyz789",
  "recorded_by": "user_123",
  "recorded_at": "2026-08-18T10:30:00Z",
  "status": "active",
  "immutable": true
}
```

## Request Format

All MCP requests follow this format:

```json
{
  "tool": "radar.search",
  "params": {
    "workspace_id": "w_123",
    "query": "search term"
  },
  "context": {
    "caller_id": "user_123",
    "workspace_id": "w_123",
    "request_id": "req_abc123",
    "timestamp": "2026-08-18T10:30:00Z"
  }
}
```

## Response Format

All MCP responses follow this format:

```json
{
  "success": true,
  "data": {
    "results": []
  },
  "error": null,
  "metadata": {
    "request_id": "req_abc123",
    "timestamp": "2026-08-18T10:30:01Z",
    "execution_time_ms": 156
  }
}
```

Error responses:
```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "FORBIDDEN",
    "message": "User role(s) [viewer] cannot access radar.remember",
    "status": 403
  },
  "metadata": {
    "request_id": "req_abc123",
    "timestamp": "2026-08-18T10:30:01Z",
    "execution_time_ms": 42
  }
}
```

## Authentication

### Foundation v0.8
Caller identity via `caller_id` context field:
```json
{
  "context": {
    "caller_id": "user_123",
    "workspace_id": "w_123"
  }
}
```

### Production v0.9+
OAuth 2.0 Bearer token in Authorization header:
```
Authorization: Bearer eyJhbGc...
```

**Token Claims** (JWT):
```json
{
  "sub": "user_123",
  "aud": "radarmatrix",
  "scope": "radar.search radar.remember",
  "role": "contributor",
  "workspace_id": "w_123",
  "exp": 1234567890
}
```

## Authorization

RADARMatrix uses role-based access control:

| Role | Can Use |
|------|----------|
| VIEWER | All read tools (radar.search, radar.recall, etc.) |
| CONTRIBUTOR | All read tools + radar.remember |
| EDITOR | All read tools + radar.remember + radar.record_decision |
| ADMIN | All operations |

Example: VIEWER cannot call `radar.remember`
```json
{
  "success": false,
  "error": {
    "code": "FORBIDDEN",
    "message": "User role(s) [viewer] cannot access radar.remember",
    "status": 403
  }
}
```

## Workspace Isolation

All operations are scoped to a workspace. Users cannot access data from other workspaces:

```json
{
  "tool": "radar.search",
  "params": {
    "workspace_id": "w_123",
    "query": "search"
  },
  "context": {
    "workspace_id": "w_123"  // Must match
  }
}
```

If workspace context is missing:
```json
{
  "success": false,
  "error": {
    "code": "INVALID_WORKSPACE",
    "message": "Missing workspace_id in context",
    "status": 400
  }
}
```

## Audit & Immutability

### Write Operations Are Audited
Every write operation (radar.remember, radar.record_decision) is logged:
```
[AUDIT] WRITE_OPERATION | user_123@w_123 | radar.remember | SUCCESS
```

### Results Are Immutable
All created resources include `immutable: true`:
```json
{
  "memory_id": "mem_abc123",
  "recorded_at": "2026-08-18T10:30:00Z",
  "immutable": true
}
```

Data cannot be modified or deleted after creation.

## Error Handling

### Common Errors

| Code | Status | Cause | Fix |
|------|--------|-------|-----|
| INVALID_REQUEST | 400 | Missing required field | Check request format |
| AUTH_FAILED | 401 | No caller_id | Provide caller_id in context |
| FORBIDDEN | 403 | Insufficient role | Use account with higher role |
| INVALID_WORKSPACE | 400 | Invalid workspace | Provide valid workspace_id |
| NOT_FOUND | 404 | Resource doesn't exist | Check entity/project ID |
| INTERNAL_ERROR | 500 | Server error | Retry or contact support |

### Error Response Example

```json
{
  "success": false,
  "error": {
    "code": "FORBIDDEN",
    "message": "User role(s) [viewer] cannot access radar.remember",
    "status": 403
  },
  "metadata": {
    "request_id": "req_abc123",
    "timestamp": "2026-08-18T10:30:01Z",
    "execution_time_ms": 42
  }
}
```
