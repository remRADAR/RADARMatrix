# Authorized Product Study

Study only user-owned, authorized, or publicly observable product behavior. Map visible screens, user flows, responsive behavior, content organization, and public integrations; record evidence and uncertainty. Do not present hidden architecture guesses as facts.

Do not bypass authentication, paywalls, rate limits, or access controls; extract private data, credentials, protected code, or restricted assets; or copy proprietary branding and assets without permission. When asked to build, implement an independent functional equivalent using the project's own design and source code.
