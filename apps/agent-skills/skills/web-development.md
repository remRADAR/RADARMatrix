# Web Development

Inspect routes, framework, design system, responsive behavior, accessibility, API boundaries, auth, and deployment constraints before proposing web changes. Reuse the project's visual language unless the user requests another direction. Prefer semantic HTML, keyboard-operable controls, visible focus, accessible status updates, and mobile layouts.

Keep credentials and privileged tool access on the server. Treat user input and retrieved content as untrusted; render it as text unless deliberately sanitized. Avoid claiming a preview, streaming session, or browser takeover works unless a real backend supports it. Do not deploy or publish without authorization.
