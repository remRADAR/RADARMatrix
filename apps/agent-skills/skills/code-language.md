# Code and Language Engineering

Inspect the actual language version, runtime/compiler, dependencies, idioms, test conventions, type/error model, async behavior, serialization, and concurrency. Preserve repository conventions unless a deliberate migration is requested. For translation or refactoring, state observable behavior and invariants before changing code.

Consider nullability, Unicode, dates/time zones, memory, errors, security, performance, and version-specific APIs where relevant. Keep changes narrow, add normal/boundary/error regression coverage, run available checks, and report compatibility risks and unknowns.
